# スキャンUX設計

## 基本方針
- ボタン操作なし・かざすだけ
- シャッター音なし（動画フレームキャプチャを使用）
- フラッシュライトなし（コンビニ・スーパーでの迷惑回避）
- 暗い場合は「明るい場所に移動してください」ガイド表示のみ

---

## スキャン状態管理

> 型定義・定数は `.claude/rules/patterns.md` パターン5 を参照。

## 状態遷移

```
idle
  ↓
detecting ←──────────────────────────┐
  ↓ 品質OK（3フレーム連続）            │
stable                               │
  ↓                                  │
processing                           │
  ↓              ↓                   │
result        error                  │
              ├─ dark       ─────────┤ 自動リトライ
              ├─ blur       ─────────┤ 自動リトライ
              ├─ motion     ─────────┤ 自動リトライ
              ├─ incomplete ─────────┘ ガイド表示して継続
              └─ api_error → idle
```

## スキャンフロー

```
カメラ常時起動（ライブ表示）
      ↓
バーコード検出を優先的に試みる（ZXing.js）
      ↓ バーコードなし
フレーム品質チェック（5fps）
  ✅ ブレなし（前フレームとの差分）
  ✅ 明るさ十分
  ✅ ピント合致（エッジシャープネス）
  ✅ テキスト領域検出
      ↓ 3フレーム連続OK
自動キャプチャ（無音・動画フレーム取得）→ Gemini送信
      ↓
結果カードがスライドイン
```

## フレーム品質チェック

> 閾値定数は `.claude/rules/implementation_rules.md` を参照。

### 自動制御の対応範囲

| 条件 | 自動制御 | 対応方法 |
|---|---|---|
| 暗い | ❌ | 「明るい場所に移動してください」ガイド表示 |
| ピントずれ | ✅ | フォーカスエリアを画面中央に強制指定 |
| ブレ | 半自動 | ISO自動調整 + 安定するまで待機 |
| ラベル範囲外 | ❌ | 全画面対象でOCR（枠で範囲制限しない） |

## ガイドメッセージ

| 状態 | メッセージ |
|---|---|
| idle | バーコードまたは原材料欄にかざしてください |
| detecting | 読み取り中... |
| stable | 読み取り中... |
| processing | 確認中... |
| error（dark） | 明るい場所に移動してください |
| error（incomplete） | ラベル全体が映るように離してください |
| error（api_error） | 通信エラーが発生しました。再度お試しください |

## キャッシュ設計

> 詳細（TTL・層の責務分担）は `.claude/rules/architecture.md` キャッシュ層の責務分担を参照。

- Layer 1：クライアントキャッシュ（TTL: 2時間）— 同一セッション内の重複スキャン防止
- Layer 2：NestJSメモリキャッシュ（TTL: 60秒）— Lambda再起動でリセットされるため短期のみ
- Layer 3：DBのexpires_at（TTL: 30〜180日）— scan_count連動で延長
