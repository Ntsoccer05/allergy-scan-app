### 商品画像の取得方法

| ケース | 画像の取得元 |
|---|---|
| バーコード商品（DB登録済み） | productsテーブルのimage_url |

| 画像なし | プレースホルダー表示（商品名のみ） |

│ 🖼️ [商品画像]             │
│ 📍 セブン渋谷店  18:23    │
│ チキン南蛮弁当   ¥298     │
│ 🔴 カゼイン・ホエイ検出   │
│                          │
│ 🖼️ [ラベル画像]           │  ← 惣菜はOCRキャプチャ
│ 📍 東京都渋谷区1-1        │  ← 未登録店舗は住所表示
│ 惣菜             ¥580    │
│ ✅ 該当なし               │
│                          │
│ ─── 3日前 ─────────────  │
│ 🖼️ [商品画像]             │
│ 📍 イオン新宿店  12:05    │
│ 牛乳プリン       ¥158    │
│ ✅ 該当なし  ⚠️期限切れ   │  ← expires_at超過で期限切れタグ
└──────────────────────────┘
```

### 期限切れタグの設計

```
履歴一覧取得時に products.expires_at を確認
        ↓
expires_at < NOW()
  → 「⚠️ 情報が古い可能性があります」タグを表示
  → タップすると「再スキャンを推奨します」メッセージ

expires_at >= NOW()
  → タグなし（通常表示）
```

期限切れはあくまで「古い可能性がある」という案内であり、判定を取り消すわけではない。再スキャンを促すことで安全設計を維持する。

### 店舗名のフォールバック設計

```
GPS座標取得
      ↓
Google Places API検索（半径100m）
      ↓ ヒット → 「セブンイレブン渋谷店」
      ↓ ミス
Google Geocoding APIで逆ジオコーディング → 「東京都渋谷区渋谷1-1」
      ↓ GPS未取得
「📍 場所不明」
```

### 価格表示ルール

> `.claude/rules/coding_rules.md` 価格表示ルールを参照。`price_confidence: high` のみ表示。

```

### 判定表現のカテゴリー別使い分け

| category | judgment_type | 判定表現 | 理由 |
|---|---|---|---|
| mandatory / recommended | allergy | 🔴 NG / 🟡 注意 | 医学的根拠あり・命に関わる |
| addiction / skin | caution | ⚠️ 含む / ✅ なし | 個人の選好・強い表現を使わない |

### 設定変更のロジック

```typescript
// アレルギーカテゴリー（allergy）
// ONにした瞬間 → partialAlertも自動ON
// OFFにした瞬間 → partialAlertも自動OFF
toggleAllergen(name)

// 配慮カテゴリー（caution）
// 単純なON/OFFのみ（partialAlertなし）
toggleCaution(name)

// 一部含む警告のON/OFF
// enabled:false の場合は変更不可（グレーアウト）
togglePartial(name)
```

### 設定変更のスキャン即時反映

```
スキャン開始
      ↓
GET /users/me（TTL:5分でキャッシュ）
      ↓
取得した設定でGeminiプロンプトを動的生成
→ 有効なアレルギー・配慮成分のみプロンプトに含める
```

### 引き継ぎ画面（新デバイス初回起動時）

```
┌──────────────────────────┐
│ ようこそ                  │
│                          │
│ [はじめる]                │
│                          │
│ 引き継ぎコードをお持ちの方  │  ← 小さめのリンク
└──────────────────────────┘
          ↓ タップ
┌──────────────────────────┐
│ 引き継ぎコードを入力        │
│                          │
│ ALRG - [    ] - [    ]   │
│                          │
│ [引き継ぎを実行]           │
└──────────────────────────┘
```

### コードのルール

```
形式：ALRG-XXXX-XXXX
  → O/0・I/1 は混同防止のため使用しない
  → 大文字英数字のみ

有効期限：発行から30日
  → 期限切れ後は再発行が必要
  → 再発行すると旧コードは即失効

1コード1回のみ使用可能
  → 使用後は is_used:true になり再利用不可
```

## 多言語対応（i18n）

### MVP段階の対応方針

```
日本語（ja）：デフォルト
英語（en）  ：設定画面から切り替え可能

その他（ko・zh等）：Phase2以降
```

### 実装方針

```
コンポーネント内にテキストをハードコードしない
すべてのUIテキストをi18nキーで管理する

// ❌ ハードコード（後で大工事になる）
<p>購入前にラベルの実物も必ずご確認ください</p>

// ✅ i18nキー（最初からこの形式で書く）
<p>{t('scan.result.caution')}</p>
```

### ロケールファイル構成

```
/locales
  /ja
    common.json
    scan.json
    history.json
    settings.json
  /en
    common.json
    scan.json
    history.json
    settings.json
```

### Geminiプロンプトの多言語対応

```
ユーザーのlocale設定をプロンプトに渡す

locale が 'ja' → 日本語で判定理由を返す
locale が 'en' → 英語で判定理由を返す

raw_textは言語に関わらずラベルの文字をそのまま返す
（翻訳しない）
```
