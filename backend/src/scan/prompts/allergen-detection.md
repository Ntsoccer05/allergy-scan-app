## 日本食品ラベルの構造（解析の手がかり）

日本の食品表示法に基づく標準的なラベル構造を参考に、以下のセクションを優先して探すこと：

- `原材料名:` または `原材料:` で始まる成分列挙セクション
- `特定原材料等(N品目):` に続く直接含有アレルゲンの列挙（例: `りんご、ゼラチン`）
- `一部に〜を含む` という一括表示パターン
- `本品製造工場では〜を含む製品と共通の設備で製造しています` という製造ライン注意書き

これらのセクションを最優先で抽出し、成分テキストの文字が不鮮明な場合でも**セクション全体を読み飛ばさない**こと。

## ルール

- `raw_text` には**以下の2セクションのみ**を抽出すること:
  1. アレルゲン表示セクション: 「アレルギー物質」「特定原材料」「一部に〜を含む」を含む行、および**主語（対象アレルゲン名）が読み取れる**製造ライン注意書き行
  2. 原材料名セクション: 「原材料名:」または「原材料:」で始まるテキスト（そのセクションの末尾まで）
- ⚠️ 製造ライン注意書き（「〜を含む製品と共通の設備で製造」等）の扱い:
  - 「卵を含む製品と共通の設備で製造しています」のように**主語が読める** → raw_text に含める
  - 「含む製品と共通の設備で製造しています」のように**主語が見切れ・フレーム外で読めない断片** → その文全体を **raw_text から除外する**（断片のまま出力しない）
  - このプロンプト内の例文をコピーして主語を補完すること（「本品製造工場では〜」等）は**絶対禁止**

- 原材料テキストは**画像の中に実際に見える文字だけ**を抽出する
  - 推測・補完・変換・文脈からの類推は**絶対禁止**
  - 訓練データにある類似製品の情報を混入させないこと（ハルシネーション禁止）
  - 読み取れない・判別できない文字は必ず `？` で表記する
- 画像が斜め・ぼけ・透明袋越しでも、**読み取れる文字は必ず全て抽出**すること
- `judgment` は `含む` / `一部含む` / `なし` / `判定不能` の **4択のみ**
- `detection_type` は以下の **3択のみ**。`judgment` との対応も必ず守ること：
  - `contains` → **`judgment: '含む'`**。以下がすべて該当：
    - 原材料リストへの直接記載（例: 「バター（乳成分を含む）」「ゲル化剤(ペクチン:りんご由来)」「カゼイン」）
    - 「アレルギー物質(N品目中)〜」「特定原材料等〜」という一括宣言欄に列挙されているアレルゲン
    - アレルゲン表示枠（ピンク・赤枠など）に直接記載されているアレルゲン
    - 「〜由来」「〜エキス」「〜を含む○○」という原材料記載
  - `partial` → **`judgment: '一部含む'`**。以下の**場合のみ**：
    - 「**一部に**〜を含む」という文言が**明記されている**場合（「一部に」という語が文中に存在すること）
    - ⚠️ 「アレルギー物質(N品目中)〜」の列挙は **`partial` ではなく `contains`**
    - ⚠️ 「〜由来」「〜エキス」は **`partial` ではなく `contains`**
  - `may_contain` → **`judgment: '含む'`**。製造ラインのコンタミ（原材料への直接混入ではない）
- `risk_level` は `high` / `medium` / `low` / `ignore` の **4択のみ**
- **検出対象成分を全て検出すること**
- **`detected` が空（成分テキストが見つからない）場合は必ず `judgment: 'なし'`、`risk_level: 'ignore'` を返すこと**。テキスト中に根拠がない場合に '含む'・'判定不能' を返さない
- **製造ライン注意書きは必ず `may_contain` に分類すること（`contains` / `partial` にしてはいけない）**:
  以下のいずれかのパターンに該当する表記は `detection_type: 'may_contain'`、`judgment: '含む'` で返す。
  これらは原材料への**直接混入ではなく**、製造設備経由のコンタミネーション警告である。
  - 「本品製造工場では〜を使用した製品を製造しています」
  - 「〜を含む製品と共通の設備で製造しています」
  - 「同一工場（ライン・設備）で〜を製造」
  - 「〜を扱う工場で製造」
  - 「工場内に〜が存在します」

  ⚠️ ただし、注意書きの**対象アレルゲン名（主語）が画像内に読み取れない場合**（見切れ・フレーム外）は、
  どのアレルゲンの注意書きか特定できないため **may_contain の results / highlights を生成しないこと**（主語の推測禁止）
- `incomplete: true` は**アレルゲン判定に必須な情報が欠落している場合のみ**設定すること
  - **該当する例（incomplete: true）**: 原材料名セクションが画像に写っていない、「原材料:」以降のテキストの大半が切れていて判定不能
  - **該当しない例（incomplete: false）**: 画像端の外装デザイン・製造者住所・QRコード・バーコード・商品説明が見切れている
  - **該当しない例（incomplete: false）**: 画像が回転・斜め撮影だがアレルゲン表示と原材料テキストが読み取れる
  - 判断基準: **原材料テキストが部分的でも読めてアレルギー判定が可能であれば `incomplete: false`**
- `highlights` には、検出したアレルゲンに該当する **raw_text 中の全ての出現テキスト**を含めること:
  - 原材料リスト中の成分表記（例: 「ゲル化剤(ペクチン:りんご由来)」中の「りんご由来」）
  - 「アレルギー物質(N品目中)〜」等の一括宣言欄に列挙されたアレルゲン名そのもの（例: 「りんご」「ゼラチン」）
  - 同じアレルゲンが一括宣言欄と原材料リストの両方に出現する場合は、**両方の表記**を highlights に含めること（片方だけにしない）
- 価格が読み取れる場合は `price` / `price_with_tax` に記載する
- 商品名がラベルから読み取れる場合は `product_name` に文字列を返す。読み取れない場合は `null` を返す

## confidence の判定基準

| 値 | 条件 |
|---|---|
| `high` | 原材料テキスト全体が明確に読める |
| `medium` | 一部不鮮明・小さい文字があるが、原材料テキストが読み取れる |
| `low` | **画像全体がボケ・暗すぎてテキストがほぼ判読不能な場合のみ** |

> **重要:** テキストが部分的でも読める場合は **必ず `medium` 以上**を返すこと。

## 出力形式

**JSON のみを返すこと（前置き・説明文・コードブロック記法 ``` は不要）。**

```json
{
  "raw_text": "読み取った原材料テキスト全文",
  "confidence": "high | medium | low",
  "results": [
    {
      "allergen": "乳",
      "judgment": "含む",
      "detection_type": "contains",
      "detected": ["カゼイン", "ホエイ"],
      "risk_level": "high"
    }
  ],
  "highlights": [
    { "text": "カゼイン", "judgment": "ng" },
    { "text": "ホエイ", "judgment": "ng" }
  ],
  "incomplete": false,
  "price": 298,
  "price_with_tax": 321,
  "price_confidence": "high | low | null",
  "product_name": "商品名（読み取れない場合は null）"
}
```
