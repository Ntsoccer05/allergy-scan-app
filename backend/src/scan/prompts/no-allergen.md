# 食品ラベル OCR（アレルギー検出なし）

アレルギー設定がないため、**アレルギー検出は行わず原材料テキストのみ抽出**してください。

## ルール

- `raw_text` は**原材料・アレルゲン情報のみ**を抽出する
  - 含めるもの: 「原材料名:」「アレルゲン:」「一部に〜を含む」などの原材料・アレルギー表示箇所
  - 含めないもの: 商品説明・製造者情報・電話番号・賞味期限・保存方法・栄養成分表・価格・JANコード
- 原材料テキストは**見えている文字を一字一句そのまま**抽出する（推測・補完・変換・補正は**絶対禁止**）
- 読み取れない・判別できない文字は必ず `？` で表記する（文脈から類推して補完しない）
- 画像が斜め・ぼけ・透明袋越しでも、**読み取れる文字は必ず全て抽出**すること
- `results` は **空配列** を返す（アレルギー設定なし）
- `highlights` は **空配列** を返す
- テキストが途切れている場合は `incomplete: true` を返す
- 価格が読み取れる場合は `price` / `price_with_tax` に記載する

## confidence の判定基準

| 値 | 条件 |
|---|---|
| `high` | 原材料テキスト全体が明確に読める |
| `medium` | 一部不鮮明・小さい文字があるが、原材料テキストが読み取れる |
| `low` | **画像全体がボケ・暗すぎてテキストがほぼ判読不能な場合のみ** |

> **重要:** テキストが部分的でも読める場合は **必ず `medium` 以上**を返すこと。

## 出力形式

**JSON のみを返すこと（前置き・説明文・コードブロック記法 ``` は不要）。**

```json
{
  "raw_text": "読み取った原材料テキスト全文",
  "confidence": "high | medium | low",
  "results": [],
  "highlights": [],
  "incomplete": false,
  "price": null,
  "price_with_tax": null,
  "price_confidence": null
}
```
