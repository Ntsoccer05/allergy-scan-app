# 完了前の検証

## 概要

検証なしに作業が完了したと主張することは、効率ではなく不誠実。

**コアプリンシパル:** 主張の前に証拠を。常に。

**このルールの文字通りの違反は、精神的な違反。**

## 鉄則

```
新鮮な検証証拠なしに完了を主張してはならない
```

このメッセージで検証コマンドを実行していなければ、パスすると主張できない。

## ゲート関数

```
任意のステータスを主張したり満足感を表現したりする前に:

1. 特定: この主張を証明するコマンドは何か？
2. 実行: 完全なコマンドを（新鮮に、完全に）実行する
3. 読む: 完全な出力を確認し、終了コードを確認し、失敗数を数える
4. 確認: 出力は主張を裏付けるか？
   - NO の場合: 証拠とともに実際のステータスを述べる
   - YES の場合: 証拠とともに主張を述べる
5. そのあとに: 主張を行う

ステップをスキップ = 嘘をついている、検証していない
```

## 一般的な失敗

| 主張 | 必要なもの | 不十分なもの |
|------|----------|------------|
| テストがパス | テストコマンド出力: 0 件の失敗 | 前回の実行、「パスするはず」 |
| リンタークリーン | リンター出力: 0 件のエラー | 部分的なチェック、推測 |
| ビルドが成功 | ビルドコマンド: exit 0 | リンターがパス、ログが良さそう |
| バグが修正された | 元の症状をテスト: パス | コードが変更された、修正されたと仮定 |
| リグレッションテストが機能 | レッド-グリーンサイクルを確認 | テストが一度パス |
| エージェントが完了 | VCS diff が変更を示す | エージェントが「成功」と報告 |
| 要件を満たした | 行ごとのチェックリスト | テストがパス |

## Red Flags — STOP

- 「should」、「probably」、「seems to」を使っている
- 検証前に満足感を表現する（「いいですね！」「完璧！」「完了！」など）
- 検証なしにコミット/プッシュ/PR しようとしている
- エージェントの成功報告を信頼している
- 部分的な検証に頼っている
- 「今回だけ」と考えている
- 疲れていて、作業を終わらせたい
- **検証を実行せずに成功を示唆するいかなる表現も**

## 言い訳防止

| 言い訳 | 実態 |
|--------|------|
| 「今は機能するはず」 | 検証を実行すること |
| 「確信している」 | 確信 ≠ 証拠 |
| 「今回だけ」 | 例外なし |
| 「リンターがパスした」 | リンター ≠ コンパイラ |
| 「エージェントが成功と言った」 | 独立して検証する |
| 「疲れている」 | 疲労 ≠ 言い訳 |
| 「部分的なチェックで十分」 | 部分的では何も証明されない |
| 「違う言葉だからルールは適用されない」 | 精神 > 文字通り |

## 主要パターン

**テスト:**
```
✅ [テストコマンドを実行] [34/34 パス] "すべてのテストがパスしました"
❌ 「今はパスするはず」 / 「正しく見える」
```

**リグレッションテスト（TDD レッド-グリーン）:**
```
✅ 書く → 実行（パス）→ 修正を元に戻す → 実行（必ず失敗）→ 復元 → 実行（パス）
❌ 「リグレッションテストを書いた」（レッド-グリーン検証なし）
```

**ビルド:**
```
✅ [ビルドを実行] [exit 0 を確認] "ビルドがパスしました"
❌ 「リンターがパスした」（リンターはコンパイルをチェックしない）
```

**要件:**
```
✅ 計画を再読 → チェックリスト作成 → それぞれ確認 → ギャップまたは完了を報告
❌ 「テストがパス、フェーズ完了」
```

**エージェントの委任:**
```
✅ エージェントが成功を報告 → VCS diff を確認 → 変更を検証 → 実際の状態を報告
❌ エージェントの報告を信頼する
```

## いつ適用するか

**常に以下の前に:**
- 成功/完了の主張のいかなるバリエーションも
- 満足感のいかなる表現も
- 作業状態についての肯定的なステートメントも
- コミット、PR 作成、タスク完了
- 次のタスクへの移動
- エージェントへの委任

**ルールは以下に適用される:**
- 正確なフレーズ
- 言い換えや同義語
- 成功の示唆
- 完了/正確さを示唆するいかなるコミュニケーションも

## 結論

**検証のショートカットなし。**

コマンドを実行する。出力を読む。それから結果を主張する。

これは交渉の余地がない。
